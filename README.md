# Lumina Cinema

A Next.js movie booking dashboard for a multiplex box office. The app uses TypeScript, Tailwind CSS, the App Router, and `src/`.

## Features

- Dark cinema desk layout with sidebar navigation
- Dashboard for occupancy, box office, and tonight’s houses
- Now showing, showtimes, bookings, screens, and reports views
- Icons via `lucide-react`

Data is mocked in `src/lib/data.ts` so the desk can be used locally without a database.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```
